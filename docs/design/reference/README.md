# Design reference PNGs

This directory holds one 1× PNG export of each of the 19 review frames that spec §11.1 lists (plan Appendix A C-11), taken from Figma file `d5tA6ap1tH4cTDaJiwve89`. These PNGs are the oracle for the T24 design review, which compares the running application against them side by side. They are project-owned and declared `GPL-3.0-only` in `REUSE.toml` (§11.1).

Each file name is the frame's node ID, with a hyphen in place of the colon, followed by a short slug. The export route is the same for every frame: the Figma MCP `get_screenshot` tool with `contentsOnly` set and `maxDimension` equal to the longer edge of the rendered image, so the render is unscaled. Every export was accepted only when the tool's reported size, its unscaled original size and the PNG header agreed.

Popup PNGs include the frame's own drop-shadow margin, as Figma renders a node with its effect bounds, so the T24 review compares the frame region at that offset. Each popup PNG is the frame size plus 32 pixels in each dimension. The offset column gives the frame's top-left corner inside the PNG, (16, 12), derived from the popups' shadow token `0 4px 16px 0`: a blur of 16 extends the bounds by 16 on every side, and the y-offset of 4 moves the shadow down, leaving 12 above the frame and 20 below it. The alpha channel confirms it for all nine popups: the derived frame rectangle is opaque at every edge and the pixel just outside it is faint shadow. The full-window frames have no margin, so their PNG size equals the frame size.
